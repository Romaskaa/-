# Синхронизация CMS с SQLite в n8n

Workflow получает данные из CMS API с учётом пагинации, сохраняет и обновляет их в SQLite, формирует CSV-файл и отправляет его в Report API.

Работа выполнена с использованием технологий n8n; база данных - SQLite.

Workflow экспортирован в JSON и находится в этом репозитории.
